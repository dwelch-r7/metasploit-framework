# Kubernetes namespace capture

The fixture projects actual namespace/pod identity, the independently verified
in-pod HTTPS control, and the original module's 403 response from run
20261109T223626-78560e. Its provenance records the unmodified console-log digest.
The complete native documents and original raw output remain in the campaign
evidence export.

Both original modules discover module-lab, then use the blank datastore option
for their pod requests, producing requests interpreted as namespace pods.
The optional-exec HTTP trace independently records its actual GET and 403.
These
focused tests stop at the client-call boundary; they do not simulate sessions,
network replies or successful execution. The functional qualification uses the
genuine K3s/pod sessions. Explicit configured namespaces are derived unit
boundaries, and 192.0.2.10 is TEST-NET-1.
