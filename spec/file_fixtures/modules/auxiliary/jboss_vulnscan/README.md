# Native JBoss credential response metadata

`credentials.json` records the accepted and rejected Basic credential HTTP
responses from the genuine all-method secured JBoss AS 4.2.3.GA / Temurin
8u412 target. The source capture path and SHA-256 identify the complete native
HTTP evidence retained by the module-target run. Headers and status codes are
copied unchanged. Body digests identify the raw bodies; the unit examples use
only status and headers and do not invent response bodies.

Database availability and workspace/credential objects are derived unit
conditions. They validate the reporting contract and do not qualify a live
Framework database. The separate container acceptance family verifies actual
credential acceptance/refusal and completion of the scanner's remaining work.
