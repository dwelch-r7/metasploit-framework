API access results from the original-source 12-case Joomla run
`20261109T185257-263630/joomla_api/native-joomla.json`. Source and producer

remaining affected. Anonymous public-query API calls work on affected targets
and are refused on 4.2.8; positive authenticated native requests establish that
the fixed endpoints are installed and functional. Unrelated Apache HTML is an
actual negative identity control.

The focused tests stub the existing common Joomla discovery helpers and test
only the owning module's check contract. Additional minimum/other-release,
blank and malformed version cases are derived boundaries, not extra native
installations or tests of the shared fingerprinting mixin.
