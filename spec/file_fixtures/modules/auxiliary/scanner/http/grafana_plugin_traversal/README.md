# Native Grafana version projections

`versions.json` projects exact version-bearing strings from full actual login
pages served by eight pinned official Grafana images. Each profile retains its
full-page digest and independently observed traversal status. The complete
native report has its own recorded path and digest. The ordinary Apache body
is also an actual capture. No response handler is substituted in functional
tests.

Focused tests use these fragments as explicit reduced parser inputs, not as
complete native HTML pages. The no-response case is synthetic. Actual version,
path traversal and file-byte behavior is independently exercised by the managed
lab before assigning any module failure.
