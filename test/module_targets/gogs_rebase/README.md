# gogs_rebase target profile

This profile selects five own-repository examples. The complementary
[existing-repository profile](../gogs_rebase_existing/README.md) selects the other
five from the original ten-case corpus, retaining every example body and repeat.
The complete native gate precedes both groups. Retained campaign reports record
the exact qualified inputs and outcomes; selection alone is not qualification.

See the [shared Gogs guide](../gogs/README.md) for primary provenance, native
prerequisites, actual payload proof, limits and cleanup boundaries. This profile
runs at most 5 containers, including Framework and reporting DB when used.
Run only this family after an explicit serial resource grant:

```bash
bundle exec ruby tools/dev/run_guarded_module_target_tests.rb gogs_rebase
```

Wait for complete owned teardown before another family or any build starts.
The expected case count is a collection contract, not a qualification result.
