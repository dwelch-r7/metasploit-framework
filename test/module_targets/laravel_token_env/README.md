# Laravel exposed environment-file discovery

```sh
MODULE_TARGET_NAMESPACE=laravel-token-env-local bundle exec ruby tools/dev/run_guarded_module_target_tests.rb laravel_token_env
```

This profile uses the genuine pinned Laravel 5.6.29 application and deliberately
copies its generated lab-only `.env` into the document root. Apache serves that
real static file; no synthetic discovery endpoint or vendor patch is added.
The configured key contains only the fixture's fixed test bytes.

Installed-class serialization and Laravel encryption controls independently
prove the three working HTTP gadgets and the hardened Faker denial. The profile
then checks real `.env` discovery, a check that reaches actual command output,
and repeated owner command execution without a configured APP_KEY. Trace events
must show environment-file discovery without using the debug-page fallback.

One capped application container runs at a time (1 CPU, 512 MiB/equal swap,
128 PIDs). HTTP binds only to loopback. Use an explicit task namespace and the
guarded runner; ensure cleanup removes the container and ephemeral network when
the phase finishes, including after errors or interruption. Before/after hashes,
healthy HTTP and cgroup readings bracket the run. Failed native prerequisites
withhold the owner verdict. Human Scenarios are not generated by this profile.
