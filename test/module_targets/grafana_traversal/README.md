# Grafana plugin traversal targets

```sh
bundle exec ruby tools/dev/run_module_target_tests.rb grafana_traversal
```

Official digest-pinned Grafana images exercise both sides of each documented
8.0, 8.1, 8.2 and 8.3 fix boundary. A separate genuine subpath installation and
ordinary Apache cover path handling and unrelated-service rejection. No
application handler or response is replaced. Only random loopback ports are
published; the only mounted target file is public read-only lab proof text.

Native vendor versions, API health, actual login pages, full file bytes and
direct traversal responses establish each target independently before module
checks and repeated collection. Nonexistent plugin/file and insufficient depth
are explicit negatives. Tests compare exact loot bytes, including Unicode and
newlines, and require each repeat to add only its own expected loot.

The [upstream advisory](https://github.com/grafana/grafana/security/advisories/GHSA-8pjx-jj86-j47p)
identifies the four fixed branch releases. Actual native responses must still
confirm this deployment; a version or running container alone is insufficient.
Other versions, beta/preview builds, authentication proxies and platforms remain
unqualified. Registration alone is not a passing result. Existing human
Scenarios are preserved.
