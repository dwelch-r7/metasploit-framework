# LinuxKI Unix/PHP bootstrap investigation controls

Run `linuxki_unix_bootstrap_controls` with the namespaced guarded runner. This
diagnostic profile enables the existing session TLV logging option and a passive
TracePoint observer. It retains actual UUID reads, stage generation and initial
encryption verification without replacing any producer or network operation.
Up to eight staging connections are observed; key values are not logged by the
observer. The ordinary TLV log is a local lab artifact.

Native package/runtime and callback gates precede two CLI sessions generated
from the same selected handler prototype, then a genuine-page control and two
fresh owner selections. All session proofs and cleanup requirements remain in
force. This separates handler reuse from LinuxKI and fresh from reused owner
selection. Instrumentation may change timing; a passing diagnostic does not
resolve the uninstrumented repeat failure by itself. No source candidate is
installed. Both capped containers are removed on every exit.
