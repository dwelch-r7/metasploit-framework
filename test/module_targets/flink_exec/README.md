# Apache Flink JAR execution profile

See the [shared native target guide](../flink_read/README.md) for pinned upstream
images, native job controls, public lab credentials, coverage and limits.

```sh
bundle exec ruby tools/dev/run_module_target_tests.rb flink_exec
```

This bounded profile has nine examples and repeats every execution or rejection.
Default staged Java Meterpreter must really spawn and open a usable session; the
inline Java shell supplies a distinct delivery path. Actual JAR/process/file
cleanup and native service health are required after each successful run.
The disabled-upload negative captures genuine multipart staging despite HTTP404
and records explicit operator restoration; it does not claim automatic removal
when the JAR API itself is disabled.
