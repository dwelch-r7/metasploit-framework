# LinuxKI ordinary default PHP session controls

Run `linuxki_php_sessions` with the namespaced guarded runner. It reuses
[the shared session fixture](../linuxki_sessions/README.md), stock Framework
PHP Meterpreter and the actual default target's single-quote bad character.
No private payload/runtime source or framing candidate is installed.
The actual resolved runtime must match its bundled package manifest and cannot
come from a local Framework/user override. Raw/decoded hashes and source bytes
are retained in the runner artifacts.

Independent callback/ack and native shell/HTTP controls precede repeated PHP
CLI sessions, then repeated genuine-page sessions. Every session requires
actual public use, UID33/PID/birth/file proof and remote shutdown. Owning default
TARGET/PAYLOAD execution is withheld unless both native delivery stages pass.
A failed stock control is retained as unqualified readiness; it does not prove
a LinuxKI exploit defect. Only successfully used and physically closed sessions
may be credited. The entire stack and all proof files are removed on exit.
